# Status da primeira versão

Componentes implementados na branch de desenvolvimento: 12 trilhas, 60 aulas curtas, 60 questões comentadas, progresso local, biblioteca com links aos materiais consultados, layout responsivo e editor C++ com análise heurística e exportação.

Para operação completa ainda é preciso ativar o GitHub Pages na branch principal e, se desejado, hospedar o Worker e uma instância Judge0 para execução real.

A análise local não equivale à compilação. A biblioteca do site organiza uma seleção acadêmica, não importa automaticamente a coleção inteira do Drive. Materiais originais não foram modificados.

Antes de considerar pronto para uso contínuo, valide o build no GitHub Actions, a interface no celular, o executor sob limites de segurança e as questões com as fontes originais.

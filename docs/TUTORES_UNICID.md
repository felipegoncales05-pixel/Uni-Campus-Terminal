# Integração com Tutores IA UNICID

Este módulo apresenta uma **seleção temática e um roteiro de estudo original**, desenvolvidos para o Campus Terminal a partir das ementas disponibilizadas no repositório público do professor Cid R. Andrade.

Fonte: https://github.com/cidandrade/tutores-ia-unicid

## O que foi incorporado

- Uma seção própria para as disciplinas **Modelagem de Banco de Dados (MBD)**, **Desenvolvimento Front-End para Web (DFW)**, **Estruturas de Dados II (ED2)**, **Paradigmas de Linguagens de Programação (PLP)** e **Design Profissional (DP)**.
- 20 unidades de revisão resumidas, baseadas nos temas declarados nas ementas de 2026.2.
- Roteiros interativos de **investigar → consultar fontes → praticar**, com perguntas de reflexão e atividades inéditas; sem fornecer respostas de avaliações reais.
- Anotações e revisões concluídas são mantidas **somente no navegador local**.
- Links individuais para ementa, índice de materiais, Drive da disciplina, skill original e ZIP de instalação.
- Simulador de notas, limitado à regra descrita pelo repositório: A1 e A2 até 5,0 cada, soma mínima 6,0, frequência mínima 75%, e AF que substitui a menor nota quando aplicável.

## Limites importantes

O painel de estudo **não é um tutor de IA conversacional**. Para conversar com um tutor, abra o projeto original, faça a instalação ou utilize as instruções do professor na ferramenta de IA compatível. O Campus Terminal não instala automaticamente arquivos `SKILL.md` nem consulta modelos externos.

A navegação para os **índices vivos** leva diretamente ao repositório do professor, onde ele atualiza links para documentos. **Não há sincronização automática dos materiais com o Campus Terminal**. A ementa e os índices devem ser consultados sempre que for necessária a versão oficial atual.

Os materiais do Google Drive não foram copiados nem republicados. Os nomes e URLs dos materiais permanecem no repositório de origem. Datas de cronogramas semestrais podem ficar desatualizadas; consulte o índice e o sistema acadêmico.

A calculadora é apenas uma simulação baseada na regra **dessas disciplinas**, não em todas as faculdades, cursos ou professores. Consulte seu sistema acadêmico para a decisão oficial.
